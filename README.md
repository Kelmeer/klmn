# РОИБ — Российское межрегиональное общество по изучению боли

Современная адаптивная версия сайта painrussia.ru.

## Стек

- Vite + React 18 + TypeScript
- Tailwind CSS (кастомная тема `ink` / `coral` / `teal` / `sand`)
- React Router
- Framer Motion (анимации появления)
- lucide-react (иконки)

## Запуск

```bash
bun install
bun run dev      # http://localhost:5173
bun run build    # сборка в dist/
bun run typecheck
```

## Структура

- `src/data/site.ts` — весь контент (навигация, новости, события, комитеты, отделения, рекомендации, материалы для пациентов)
- `src/components/layout` — Header (мега-меню + мобильное меню), Footer, Layout
- `src/components/ui` — кнопки, логотип, PageHero, формы, Reveal-обёртки
- `src/pages` — страницы: главная, об обществе, президиум, комитеты, отделения, молодые учёные, конференции, образование, специалистам, клинические рекомендации, пациенту, контакты, авторизация, личный кабинет, новости, журнал, карта сайта, поиск, 404

## Авторизация

Демо-реализация на `localStorage` (`src/lib/auth.tsx`): регистрация/вход, защищённый маршрут `/account` с редиректом на `/auth?tab=login`.
